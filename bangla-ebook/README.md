## অনুবাদ নীতিমালা

- মূল বইয়ের **সব অধ্যায়, ব্যাখ্যা, ল্যাব নির্দেশনা ও 31টি ছবি** রাখা হয়েছে।
- **কোড, টার্মিনাল কমান্ড, উদাহরণ প্রম্পট, টুল/মডেলের নাম ও URL হুবহু ইংরেজিতে** রাখা হয়েছে, কারণ ল্যাবে এগুলো হুবহু এভাবেই লিখতে হয়। প্রতিটির অর্থ আশপাশের বাংলা লেখায় এবং ছবির বাংলা ক্যাপশনে বুঝিয়ে দেওয়া হয়েছে।
- স্ক্রিনশটগুলোর ভেতরের লেখা ল্যাবের আসল ইন্টারফেসের ইংরেজি; ক্যাপশন বাংলায়।
- মূল PDF-এর পৃষ্ঠার ওয়াটারমার্ক এই সংস্করণে নেই। বইয়ের শেষে অনুবাদক-সংযোজিত পরিভাষা তালিকা (glossary) যোগ করা হয়েছে।
- মূল বইটি **Setup** পরিচিতির পরেই শেষ হয়েছে (পরবর্তী ধাপগুলো মূল মডিউলের ইন্টারেক্টিভ ল্যাবে করতে হয়); বাংলা সংস্করণেও সেটি উল্লেখ করা হয়েছে।

## আবার বিল্ড করা (Rebuild)

```bash
pip install fpdf2 uharfbuzz pymupdf pillow
cd bangla-ebook/work
python3 assemble.py   # src/*.md থেকে book.md ও চূড়ান্ত .md তৈরি করে
python3 build_html.py # Prompt-Injection-Attacks-Bangla.html তৈরি করে
python3 build_pdf.py  # Prompt-Injection-Attacks-Bangla.pdf তৈরি করে
```

কারিগরি টীকা: PDF-এ বাংলা যুক্তাক্ষর/ো-কার/ৌ-কার ঠিকঠাক দেখাতে `fpdf2`-এর HarfBuzz
shaping চালু রেখে কাস্টম line-wrap + `cell()` দিয়ে লাইন রেন্ডার করা হয়েছে
(`multi_cell()` বাংলা vowel sign গুলো ভেঙে ফেলে)। ফন্ট: Hind Siliguri (Google Fonts, OFL)
ও DejaVu Sans Mono — দুটোই `work/fonts/`-এ রাখা আছে।
সেই কারণে PDF থেকে বাংলা টেক্সট কপি করলে কিছু যুক্তাক্ষর অপূর্ণ আসতে পারে;
কপি/খোঁজার জন্য HTML বা Markdown সংস্করণ ব্যবহার করুন।
